## 🌌 Overview

**Constellation25 is not a monolith — it is a living, breathing swarm of 25 specialized AI agents**, each modeled after a celestial body and engineered to own a specific domain of the AI empire. This is the complete sovereign AI ecosystem by FacePrintPay, orchestrating intelligence across multiple dimensions.

### The Constellation Philosophy

Each of the 25 agents represents a celestial body with unique capabilities:
- **Autonomous Operation** - Each agent owns its domain
- **Interconnected Intelligence** - Agents collaborate through the swarm
- **Sovereign Architecture** - Decentralized, resilient, scalable
- **Emotional Intelligence** - PaThos-powered emotional awareness
- **Knowledge Mastery** - VeRseD-driven knowledge management

## 🚀 Quick Start

### Prerequisites

```bash
# Core Requirements
- Python 3.9+
- Node.js >= 18.0.0
- npm >= 9.0.0
- Git
```

### Clone the Constellation

```bash
# Clone the main monorepo
git clone https://github.com/FacePrintPay/c25-monorepo.git
cd c25-monorepo

# Install dependencies
npm install

# Clone the Python swarm engine
git clone https://github.com/FacePrintPay/constellation25.git
cd constellation25
pip install -r requirements.txt
```

### Initialize the Swarm

```bash
# Start development mode
npm run dev

# Or start the Python swarm
python constellation25/swarm.py --init

# Launch all agents
./c25-master/launch.sh --full-constellation
```

## 🔌 API Endpoints

### C25 Agent API (Monorepo)

```
Base URL: /api/c25

GET  /health              # Health check
POST /auth/*              # Authentication
GET  /arxiv/*             # ArXiv search
GET  /weather/*           # Weather service
POST /upload/*            # File uploads
GET  /search/*            # Search
POST /payment/*           # Payments
POST /graphql             # GraphQL endpoint
```

### PaThos AI API

```
Base URL: /api/pathos

POST /auth/*              # Authentication
GET  /sentiment           # Sentiment analysis
POST /license             # License validation
GET  /emotional-state     # Current emotional state
```

### Swarm Control API

```
Base URL: /api/swarm

GET  /agents              # List all agents
GET  /agents/:id          # Agent details
POST /agents/:id/start    # Start agent
POST /agents/:id/stop     # Stop agent
GET  /swarm/status        # Overall swarm status
```

## ⚙️ Configuration

### Environment Variables

Create `.env` files in respective directories:

```env
# Core Configuration
PORT=3000
NODE_ENV=development
PYTHONPATH=./constellation25

# Authentication
JWT_SECRET=your-secret-key
GITHUB_TOKEN=your-github-token

# Database
DATABASE_URL=mongodb://localhost:27017/c25
REDIS_URL=redis://localhost:6379

# AI Services
PATHOS_API_KEY=your-pathos-key
VERSED_API_KEY=your-versed-key

# Deployment
C25_AGENT_DEPLOY=true
SWARM_SIZE=25
```

### Swarm Configuration

```yaml
# constellation25/config.yaml
swarm:
  name: "Constellation25"
  total_agents: 25
  coordination_protocol: "decentralized"
  
agents:
  - id: 1
    name: "Prime"
    role: "orchestrator"
    auto_start: true
    
  - id: 3
    name: "Pathos"
    role: "emotional_intelligence"
    auto_start: true
```
